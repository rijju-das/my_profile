# Riju Das — Research Portfolio

An interactive research portfolio focused on affective computing, computer vision and multimodal AI. The site presents Riju's research as a connected journey from visual signals to meaning and inspectable evidence.

## Sections

- Interactive research atlas
- Selected research projects and architectures
- Filterable recent publications
- Research, teaching and education timeline
- Funding, awards, academic service and technical expertise

The site is built with semantic HTML, modern CSS and lightweight JavaScript. It has no framework or build dependency and can be served from any static host, including GitHub Pages.
